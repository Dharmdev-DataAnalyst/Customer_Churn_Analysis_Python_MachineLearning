# Customer Churn Analysis | Python & Machine Learning

##  Project Overview

Customer Churn Prediction is a Machine Learning project focused on analyzing customer behavior and identifying customers who are likely to leave a company's services.

In this project, I performed Exploratory Data Analysis (EDA), data cleaning, data visualization, and Machine Learning model building using Python. Different classification and regression algorithms were explored to understand patterns in customer data and evaluate model performance.

The primary objective is to understand customer churn patterns and build predictive models that can help businesses improve customer retention.

##  Project Objectives

- Analyze customer data to identify important factors influencing customer churn.
- Perform data cleaning and preprocessing using Pandas.
- Conduct Exploratory Data Analysis (EDA).
- Create visualizations to understand customer behavior and churn patterns.
- Build and evaluate different Machine Learning models.
- Compare model performance using appropriate evaluation metrics.

##  Project Workflow

### 1. Data Cleaning & Preprocessing
- Loaded and explored the customer churn dataset.
- Checked missing values and duplicate records.
- Performed data preprocessing and prepared data for model building.

### 2. Exploratory Data Analysis (EDA)
- Analyzed customer characteristics and churn distribution.
- Explored relationships between different customer attributes.
- Used charts and visualizations to identify meaningful patterns.

### 3. Data Visualization
Created visualizations to understand:
- Customer churn distribution.
- Customer behavior and patterns.
- Relationships between customer features.
- Factors associated with customer churn.

### 4. Machine Learning Model Building

Implemented and explored the following Machine Learning algorithms:

**Linear Regression**
- Applied regression techniques and evaluated prediction performance.

**Logistic Regression**
- Built a classification model to predict customer churn.

**Decision Tree**
- Implemented a tree-based model to classify customers based on their features.

### 5. Model Evaluation

Evaluated model performance using the following metrics:

| Evaluation Metric | Purpose |
|---|---|
| Accuracy Score | Measures the proportion of correct predictions |
| Confusion Matrix | Evaluates correct and incorrect classification results |
| Mean Squared Error (MSE) | Measures the average squared prediction error |
| Root Mean Squared Error (RMSE) | Measures prediction error in the target variable's original scale |
| R² Score | Measures how well a regression model explains variation in the target variable |
